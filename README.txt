SANSKAR PALACE BANQUET HALL WEBSITE

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the sanskar_palace_website folder.
3. Double-click index.html. It should open in your default browser; if needed, right-click it and choose Open with > Google Chrome.
4. Keep the photos folder beside index.html so all images load.

The first section of the homepage contains all five supplied photos.
The phone number, address, Google Maps link and WhatsApp enquiry are included.
The enquiry form opens WhatsApp with the details filled in; it does not store enquiries on a server.

To publish it publicly, upload the extracted folder contents to a static hosting provider. This ZIP does not itself create a public website URL.
